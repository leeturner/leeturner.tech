Profile

I am an experienced software engineer with over 20 years experience working on large scale software implementations and have a passion for well crafted, pragmatically tested software. My specialties are in Java & Kotlin microservice architectures, test-driven development and agile software development.

Projects

Micronaut Launch TUI

  • Open Source
  • TUI
  • Kotlin
  • Micronaut

mtui is a terminal UI for creating Micronaut projects through Micronaut Launch, written in Kotlin and built with TamboUI. It puts the hundreds of available Micronaut features in one searchable list, lets you preview the generated files and unzips the project straight into the current directory without ever leaving the terminal

wiremock-micronaut

  • Open Source
  • Library
  • Kotlin
  • Micronaut
  • WireMock

wiremock-micronaut simplifies testing HTTP clients in Micronaut 5 and above. It starts WireMock servers per test class, binds their URLs into Micronaut configuration before your beans are created and injects them into your tests. The annotations mirror wiremock-spring-boot and it is available on Maven Central

wiremock-blns-extension

  • Open Source
  • Library
  • WireMock

wiremock-blns-extension is a WireMock extension that adds a naughtyString Handlebars helper, so templated responses can return strings from the Big List of Naughty Strings - SQL injection, RTL text, zero-width characters, emoji, Zalgo text and more. It works with both embedded WireMock and the standalone JAR / Docker image and is available on Maven Central

Xport

  • Open Source
  • CLI
  • Kotlin
  • Micronaut

Xport is a command-line tool built with Kotlin and Micronaut that processes Twitter data exports, converting them from JavaScript format to standard JSON and then to Hugo-compatible Markdown. This allows the tweets to then be used in a Hugo compatible microblog like this one

Conway’s Game of Life

  • Open Source
  • Kotlin
  • Micronaut
  • Arrow

A terminal based implementation of Conway’s Game of Life written in Kotlin using Micronaut and functional programming with Arrow. The universe wraps around like a torus and can be rendered in the terminal with ANSI colours or in a KorGE 2D window

Spektrum

callback-logger

  • Open Source
  • Kotlin
  • Micronaut

callback-logger is a simple Kotlin and Micronaut service to receive callbacks, which is useful when testing APIs locally that send them. It logs every POST or PUT it receives with a simple web UI to see what has arrived, and supports custom callback endpoints with configurable response codes and payloads

image-term

  • Open Source
  • CLI
  • V

image-term is a terminal based image viewer written in V that renders images as colourful ASCII mosaics. It scales the image to fit your terminal, corrects for the aspect ratio of terminal characters and averages the colours within each block of pixels

Hugo Progression Framework

  • Open Source
  • Hugo
  • template

Hugo Progression is a Hugo template that can render progression frameworks using the same data format as the Monzo progression framework. A progression framework (or competency matrix, career ladder, career pathway) is a tool to help people within an organisation understand where they currently are and how to progress and grow in their work. It also helps an organisation map people’s competencies (their skills and knowledge) to compensation (how they’re rewarded for them financially) - find out more information in this blog post or on GitHub

BlinkyTapeTestWatcher

  • Open Source
  • Kotlin
  • JUnit

BlinkyTapeTestWatcher is a fun little Kotlin based implementation of the Junit 5 TestWatcher API that hooks up your tests to a BlinkyTape LED strip - find out more information in this blog post which also contains a video of it in action

pinboard2markdown

  • Open Source
  • Kotlin
  • Spring Boot

pinboard2markdown is a command line tool written in Kotlin and Spring Boot that communicates with the pinboard.in api to retrieve a selection of bookmarks that are tagged with a specified tag. It then converts those bookmarks to markdown and outputs them to the terminal. I use this tool to build regular newsletters for the backend developers at Crunch and to generate my Geek Reads posts
