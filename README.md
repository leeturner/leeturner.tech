# leeturner.tech
Hugo site for my cv

- CV content lives in `data/cv.toml` (text fields support markdown); site settings live in `config.toml`.
- The theme is `themes/leeturner-cv`, a single page layout sharing the palette and fonts of leeturner.me, with light/dark mode and a print stylesheet for A4.
- Icons in `data/cv.toml` use plain names: `email`, `globe`, `github`, `linkedin`, `mastodon`, `bluesky`, `rss`.

Run locally with `hugo server`.
